Importing from Excel

This brings spreadsheet rows into a table here. Your spreadsheet's column names do not have to match anything — you line them up yourself in step 4.

Step 1 — pick the table you're loading into

Records land in this table only.

Step 2 — get your spreadsheet ready

  1. Row 1 must be your column headers. Delete any title rows, logos, or blank rows above them. The first row of what you copy is treated as the header row.
  2. Unmerge any merged cells and delete fully blank columns. Merged cells shift everything to the right of them and quietly misalign the import.
  3. Check for stray text below your data — totals rows, notes, "END OF LIST". They come in as records.
  4. Format ID columns as Text before you copy. Asset tags and serials with leading zeros lose them in Excel's General format, and long numeric serials turn into scientific notation. What you see in the cell is what gets copied.
  5. Dates come across as the text Excel is displaying. Set the column to the format you want stored before copying.

Step 3 — get the data in here

  • Paste method (fastest). In Excel, select your header row and all data rows, press Ctrl+C, click the box below, press Ctrl+V, then click "Read pasted data". Select whole columns by clicking the column letters if it's easier — trailing empty rows are dropped automatically.
  • File method. In Excel use File → Save As and choose CSV UTF-8 (Comma delimited), then pick that file below. Plain "CSV (Comma delimited)" works too, but UTF-8 preserves accents and symbols. Only the active worksheet is saved — if your data is spread across sheets, export each one and import it separately.

Step 4 — match the columns

Merge matches on the identifier field — the one marked with a key on the Tables & fields page. A row whose identifier already exists updates that record; anything else is added. Blank cells in your sheet never wipe out data that's already here.

If it goes wrong

Nothing is written to your file until autosave runs about a second after the import. Before a large or first-time import, click Export read-only copy — that file is a complete snapshot you can fall back on. Every import also writes a change log entry with the counts, so you can see exactly what a run did.

    Automatic backups

    Pick a folder and the app drops a dated snapshot into it as you work — on every manual save, and periodically during autosave. It keeps the newest and deletes older ones. Each snapshot is a complete, openable copy of this app with its data.

    Put this somewhere separate from the master file — a different drive or share, so one bad disk doesn't take both.
